\# Smart Delivery Planning – Fractional Knapsack



A menu-driven C program that solves the \*\*Fractional Knapsack Problem\*\* using the \*\*Greedy Algorithm\*\*.



\## Features



\- Enter and display package details

\- Calculate Value/Weight ratios

\- Sort packages by decreasing ratio

\- Select complete or fractional packages

\- Calculate maximum achievable value

\- Display selected packages and fractions



\## Algorithm



Packages are selected in decreasing order of their \*\*Value/Weight ratio\*\*. Complete packages are selected whenever possible; otherwise, a fraction of the next package is selected.



\## Complexity



\*\*Time Complexity:\*\* O(n²)  

(Bubble sort is used to arrange packages by ratio.)



\## Language



\- C



\## Example



For a vehicle capacity of `15`:



\- Package 3 → 5 kg, Value 50

\- Package 1 → 5 kg, Value 40

\- Package 4 → 4 kg, Value 20

\- Package 2 → 1 kg, Value 3



\*\*Maximum Value = 113\*\*
